# Математический анализ · III семестр

[Скачать цветной конспект (PDF)](s3/notes-colored.pdf)

Функциональные последовательности, функциональные ряды и степенные ряды. Единственный редактируемый источник текста и формул — LaTeX в `s3/`. PDF начинается с названия и оглавления; определения, теоремы, следствия и примеры оформлены цветными блоками.

Оформление адаптировано из [ivanshemidko/algebra-notes](https://github.com/ivanshemidko/algebra-notes), [s2/main.tex](https://github.com/ivanshemidko/algebra-notes/blob/d52e89ab46b905aac035e556794af91aec7c86ef/s2/main.tex): CMU Serif, A4, поля 22/22/25/27 мм, цветные блоки, колонтитулы и оформление доказательств.

## Сборка

Нужны LuaLaTeX, latexmk, Make, Python 3 и Poppler. Для Ubuntu/Debian:

```sh
sudo apt-get update
sudo apt-get install -y make python3 latexmk texlive-luatex texlive-latex-extra texlive-lang-cyrillic texlive-fonts-recommended poppler-utils
make check
```

Четыре начертания CMU Serif установлены внутри проекта в `s3/fonts/` и подключаются по пути. Локальная сборка и CI используют одни и те же файлы; установка системного шрифта не требуется. Лицензия SIL OFL и сведения об авторах находятся в [s3/fonts/LICENSE](s3/fonts/LICENSE).

`make pdf` собирает документ через LuaLaTeX и latexmk и обновляет **`s3/notes-colored.pdf`**. Промежуточные файлы находятся в игнорируемом `s3/.build/`; `make clean` удаляет их. Можно запустить latexmk напрямую из `s3/`:

```sh
cd s3
latexmk main.tex
cp .build/notes-colored.pdf notes-colored.pdf
```

Проверка источников без сборки:

```sh
python3 scripts/check_pdf.py --sources
```

Полная проверка `make check` сверяет метки и внутренние ссылки, номера всех объектов и формул, полноту служебной привязки, наличие четырёх векторных рисунков, встроенный шрифт и границы текста в PDF. Неразрешённые ссылки, потерянные символы и переполнения в журнале сборки приводят к ошибке.

## Структура и редактирование

- `s3/main.tex` — название, оглавление, три темы и порядок подключений.
- `s3/config.tex` — общее оформление, окружения и счётчики.
- `s3/themes/sequences/`, `series/`, `power-series/` — отдельные файлы по темам и подтемам.
- `s3/figures/` — четыре векторных PDF, подключаемых через `\includegraphics`.
- `sources-manifest.json` — служебная привязка страниц рукописей к `.tex` и `\label`, контрольные суммы оригиналов и инвентаризация содержания. В документ она не включается.

При добавлении материала используйте окружения `definition`, `theorem`, `cor`, `example`, `proof`, а для нумерованных формул — `equation`. Ссылки оформляйте через `\ref` и `\eqref`; существующие метки сохраняйте. Подключите новые файлы в `main.tex` и обновите привязку и инвентаризацию в `sources-manifest.json`. После `make check` просмотрите PDF, особенно длинные формулы, оглавление и переходы доказательств между страницами.

Рукописные оригиналы хранятся только локально в корне или `sources/`, исключены из Git и не нужны для сборки. Если оригиналы доступны, проверка дополнительно сверяет их SHA-256.

## Автоматическая сборка

[Workflow](.github/workflows/pdf.yml) при изменении исходников в `main` собирает и проверяет только цветной PDF, затем сохраняет `s3/notes-colored.pdf` в репозитории отдельным коммитом. Обновление пропускается, если за время сборки появился более новый commit исходников. Коммит самого PDF повторную сборку не запускает.

В pull request выполняется сборка и проверка с доступом только на чтение; результат доступен в артефакте workflow. Запись в репозиторий выполняется отдельным заданием только для `main`. Сборку также можно запустить вручную в Actions.
